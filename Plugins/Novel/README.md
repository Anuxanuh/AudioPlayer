# 小说章节插件

需要支持插件 API 2 的新版声屿（此插件随附的主程序已支持）。在设置启用“小说章节”后，从托盘退出并重启。插件默认关闭，所有小说、字幕、匹配索引和缓存只在本机处理，不调用网络接口。

## 使用

1. 在宿主“我的音乐”选择播放列表，再进入“小说章节”，选择 TXT 小说。现存音频需有同文件夹同名 LRC。支持 UTF-8、UTF-16、GBK 自动检测，也可以指定编码。
2. “解析预览与校对”显示原始卷标题、卷序号、章序号和章节顺序；可编辑标题、正文、归属卷，移动、合并、按正文光标拆分章节，或统一修改本卷标题。“应用校对”持久保存修改；“撤销未应用修改”恢复当前已应用版本。顺序列从 0 起，章节展示从 1 起。
3. “设置”可修改章节／分卷／特殊章节／忽略行正则、单位、序号格式和是否带标题名称。正则支持命名组 `number`、`title`，以及 `{number}`、`{units}` 占位符。匹配超时会报错，避免复杂规则卡住播放器。分卷优先时使用原文卷标题；没有分卷或关闭分卷时按每 N 章分组。
4. “定位当前进度”使用当前音频时间；“生成缓存”保存整份对应关系。有缓存自动跟踪跨章节；无缓存只在点击定位或开启“解析后自动定位一次”时匹配。关闭自动定位不影响已有缓存的跨章节跟踪。
5. 点击章节查看正文、音频片段和起止时间，悬停片段查看匹配依据。“播放本章”从第一个可用片段开始，“播放选中片段”跳到指定位置；全部缺失时选中最近可用章节并提示，再次点击播放确认。
6. “片段校对”可以改秒数、删除错误片段、按当前播放位置添加片段并保存；时间不能重叠。保存会生成缓存，旧版本可通过“回滚缓存”恢复。

## 匹配与缺失

第一首现存音频前 40 条字幕优先按章节序号／标题锚点、再按正文定位。正文使用本地四字符索引和候选片段相似度；短句、重复正文或低置信度匹配会留空。第一首的两种匹配都失败时，选择起始章节并点“设为异常起点”。章节可跨多个音频，同一音频也可对应多个章节。

字幕时间戳和偏移会解析，空白字幕及未匹配广告不会强行归入章节，单句支持区间最多 45 秒。映射是字幕证据所支持的片段，不保证覆盖整本书；ASR 错误、改编、重复卷内章号等可能需要校对。相邻音频有章序跳跃时标“可能缺失”，不足以推断时标“未知区间”，不虚构已删除文件名。

缓存优先保留历史音频与小说内容；播放列表删除音频后，后台标记缺失但不丢弃映射。新增／重排音频可手动重新生成。切换播放列表自动加载其绑定，没有绑定时提示选择小说。重新选择／重新解析／应用章节校对会解除缓存绑定，之后可重新生成；已生成的其他缓存不会自动删除。

## 文件与构建

设置、播放列表绑定和校对预览默认位于 `data/plugins/novel`；缓存为可读 UTF-8 JSON，可在设置指定目录。写入采用临时文件替换，并保留 `.bak`。小说哈希、完整章节、音频列表、时间片段、匹配依据、缺失推断及版本均保存在缓存。程序目录内的路径相对存储，外部路径保持原样。

在项目源码中双击 `Plugins/Novel/build.cmd` 可独立编译并生成插件 ZIP；需要 PowerShell 7 与 .NET 10 SDK。源码根目录的 `build.cmd` 会同时打包本插件。插件 ZIP 是运行包，解压到新版声屿目录，得到 `plugins/novel`；不含小说、缓存或用户配置，也不需要 Python。
