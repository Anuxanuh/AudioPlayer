# 声屿 · Windows x64 便携版

本包所含插件：{{PLUGINS}}。
本包所含语音识别模型：{{MODELS}}。
此压缩包不附带播放列表、用户设置、音频、歌词、日志或下载缓存；具体构建选择见 `package-manifest.json`。
已附带 .NET 桌面运行时、独立 Python、faster-whisper、CTranslate2、SentencePiece、py3langid 语言识别库和 OpenCC 本地繁简字典，无须预装 .NET 或 Python。语音及翻译权重按包清单提供，翻译权重不包含在默认压缩包中。
如本包包含 Bilibili 插件，其 yt-dlp、二维码库和 FFmpeg 也已附带，不需要浏览器运行时。所有插件默认关闭。

## 开始使用

1. 将整个 ZIP 解压到有写入权限的文件夹，双击 `AudioPlayer.exe`。请保留目录中的全部文件，不要只复制 exe。
2. 添加音频即可播放；单击底部封面展开歌词界面。点击任意歌词行跳转到该句，暂停时保持暂停。
3. 使用识别功能前，在“设置 → 离线识别引擎”选择本包附带的模型。无模型的包可通过“在线模型与下载”下载多语言模型，或选择本地已有的完整 faster-whisper / CTranslate2 模型目录。下载完成后自动更新模型选择框。
4. 点击“检测本机环境”和“检查选中模型”检查依赖。模型下载完成后，音频识别完全在本机运行，不调用云端识别 API。

## 离线歌词翻译

在“设置 → 歌词翻译与显示”设定译文语言，下载约 930 MiB 的 M2M100 翻译模型或选择已有的完整模型目录。原文语言在本地自动识别，默认使用 CPU，可选 CUDA。模型下载后可断网翻译，不上传歌词。

翻译保存到音频同目录的 `歌曲名.语言代码.lrc`，例如 `歌曲名.zh.lrc`，保留原文和时间戳。已有译文默认不覆盖，可显式勾选覆盖。任务支持取消，失败或取消不会保存半成品。

歌词面板选择译文或双语模式时，会自动翻译缺少对应语言译文的歌曲，无需点击翻译按钮。已有译文直接读取；没有原文 LRC 时等待载入或语音识别完成。切歌或切回原文模式会取消当前自动翻译。三种模式同时作用于主界面与横排、竖排桌面歌词。

手动批量任务在左侧“歌词翻译”页面，可添加音频或 LRC、加入播放列表、开始或取消翻译、勾选覆盖已有译文。目标语言统一在设置页更改。模型可随整个程序目录一起移动到离线电脑。

## Bilibili 插件

以下功能适用于包含 `bilibili` 插件的包。
在“设置 → 插件”勾选 Bilibili 下载，然后从托盘右键退出播放器并重新启动。左侧会出现“Bilibili 下载”。
点击“扫码登录 Bilibili”，用 Bilibili App 扫码并在手机确认；凭据加密保存在本机，换电脑后需重新登录。
输入 BV 号并读取视频，多 P 默认全选，可逐个勾选。默认只下载音频；选择清晰度并勾选视频后，会下载音视频并使用 FFmpeg 合并为 MP4。勾选字幕会保存可获取的 SRT 和同名 LRC；实际清晰度和字幕取决于视频与账号权限。
支持“全选／全不选／反选”。Ctrl + 单击切换单集勾选，Shift + 单击按起点状态连续勾选或取消；范围外的勾选保持不变。先全不选、勾选起点，再 Shift 点击终点可快速选中一段。
插件通信与字幕使用 UTF-8，无需修改 Windows 区域编码设置。
默认保存到 `Downloads/Bilibili`，支持选择其他目录、取消和片段续传。发行包不包含下载内容或登录凭据。
更多说明见 `plugins/bilibili/README.md`。

## 小说章节插件

以下功能适用于包含 `novel` 插件的包。
在设置启用“小说章节”，托盘退出并重启后出现侧栏入口。选择宿主播放列表，再选择 TXT 小说；播放列表音频应带同名 LRC。“解析预览与校对”可修改标题、顺序、分卷及拆分合并。点击“定位当前进度”或“生成缓存”；有缓存会自动跟踪跨章节，无缓存只按需定位。章节详情可跳转播放，片段可手动校对并回滚缓存。匹配不足或已删除音频会标记未知／缺失，不上传任何文本或音频。配置和完整使用说明见 `plugins/novel/README.md`。

支持多线程批量识别、暂停／继续、边听边识别、倍速播放、桌面横排／竖排歌词、托盘和单例。
批量生成的 LRC 默认保存在音频同文件夹，使用同名文件；默认跳过已有歌词。
“识别结果自动转为简体中文”默认开启，可在设置中关闭，修改从下一次识别任务生效。

CPU 识别不需要 CUDA。使用 NVIDIA GPU 识别时，目标电脑需自行安装兼容驱动、CUDA 12 / cuBLAS 12 和 cuDNN 9；环境检测窗口提供官网下载链接。

程序运行后才会生成 `data`（配置）和 `logs`（日志）目录；`models` 保存本包附带或后续下载的模型。
日志按本机时间每小时一个文件 `logs/AudioPlayer-yyyyMMddHH.log`，运行期间自动清理超过 7 天的应用日志。
桌面歌词会检查窗口的隐藏、最小化、置顶和屏幕位置，并尝试恢复异常状态。反馈显示问题时，请提供复现步骤、显示器配置、发生时间和对应日志，并隐藏其中的私人信息。

默认关闭主窗口会缩到右下角托盘，右键托盘图标退出；设置中可以更改关闭行为。
需移动程序时复制整个解压目录；外部音频的绝对路径不会随程序一起移动。

第三方许可证见 `licenses` 和 `python/Lib/site-packages/*.dist-info`。
